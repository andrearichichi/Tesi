# VolleyVisionAI – Bachelor Thesis

This repository contains the material related to my Bachelor's thesis developed at the University of Trento.

The thesis presents **VolleyVisionAI**, a web application for volleyball video analysis designed to provide an accessible alternative to professional sports analytics tools.

The system includes two main modes:
- **Manual analysis**, allowing users to tag events, annotate frames, and generate video highlights.
- **AI analysis**, using computer vision models to track the ball trajectory and identify players.

The application architecture combines **React.js** for the front-end and **FastAPI** for the back-end, integrating **YOLOv9** and **OpenCV** for video analysis.

The goal of the project is to provide a simple and intuitive tool for **coaches and amateur athletes**, enabling performance analysis through video data.
